# Tabletop exercise: overdue hiker, Cory Pass (FICTIONAL)

Load it from the home screen: **Load tabletop exercise: lost hiker**. Everything is made up.

## Roles (4 to 8 players)
| Role | Uses |
|---|---|
| Incident Commander | Command post laptop: Overview, ICS 201/202, Op periods & handovers |
| Planning Section Chief | ICS 202-208, Print IAP, rollover |
| Operations Section Chief | Teams & assignments, ICS 204 |
| Field team leaders (2-3) | Phones, Field view (join with the incident code) |
| Exercise controller | This script; delivers injects |

Setup: create the exercise on the command laptop, read the incident code from the top bar, and have field players join on their phones ("Field team"). If cloud sync is not configured yet, run everyone on one device and hand it around.

## Debrief questions
- Did data entered once (objectives, org, channels) show up correctly across the forms?
- Was the handover summary enough for the incoming person?
- Did the field phones work with no signal and catch up afterwards?
- What did you reach for that wasn't there?
